1. **#60 병합.** 10-13 일지에 `v0.12.0-kwh.1` 배포 결과 섹션을 추가한 문서 전용 PR. 사용자가 CLA 체크 후 병합을 지시했고 CI는 모두 green이었다. `--merge`, `main` = `b38b5c744921e04a2a50fb19203edc3d1093a417`. 태그·빌드·배포를 일으키지 않았다. 로컬 `main`은 `git pull --ff-only`로 동기화.
2. **개발 PC 롤백 데이터 삭제.** 사용자 지시로 `~/openwebui-local-test-data.rolled-back-20261012-193551`(892 MB)을 삭제했다. 삭제 전에 대상이 이 디렉터리 하나뿐이고 로컬 테스트 컨테이너가 없음을 확인했다.
3. **로컬 게이트 백업 정리.** `~/openwebui-local-test-data.backups`(6.3 GB)를 판단해 사용자 권고안 승인 후 **파일명을 하나씩 지정해** 정리했다. 삭제: 7월 30일~10월 6일 백업 6개와 9월 4일 OpenAI 연결 설정 메모(JSON, 시크릿이 들어 있을 수 있어 값은 읽지 않았다). 보존: `20261012-184618-v0.12.0-kwh.1-rc.1.tar.gz`(마이그레이션 전 `d4c1a8e37b62` 고정 자료), `20261012-193704-v0.12.0-kwh.1.tar.gz`(최신 복원 지점). 합계 1.6 GB. `~/openwebui-local-test-data`와 pipelines 백업(22 KB × 3)은 건드리지 않았다.
4. **개발 환경(OMC) 정리 — 프로젝트 외부.** 사용자가 보고한 HUD 미갱신 문제를 조사했다. 마켓플레이스 로컬 클론이 `v5.7.2` 태그에 detached로 고정돼 `v5.7.3`이 들어오지 않는 것이 원인이었고, HUD(`statusLine`)는 플러그인 등록과 무관하게 `~/.claude/hud/`의 복사 스크립트로 캐시의 최고 버전을 따라간다. 사용자가 마켓플레이스를 제거 후 GitHub 소스(`yeachan-heo/oh-my-claudecode`)로 재등록했다. 개발 에이전트는 `/plugin` 명령을 실행하지 않았다(사용자 실행).
