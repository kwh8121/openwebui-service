## 3. upstream 변경 중 fork 에 영향이 있을 수 있던 항목과 판정

| 항목                                                  | 판정                                                                                                                                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 폰트 11개·`pdf-style.css` 삭제 (NotoSansKR 포함)      | **무영향.** upstream 릴리스 노트: "두 벌의 폰트는 아무도 로드하지 않았다". 코드 참조도 0건 (`About.svelte` 의 Twemoji 크레딧 링크 제외).                                        |
| 새 `Dockerfile` (`USE_SLIM`, `uv`, 슬림 변형)         | **호환.** `USE_SLIM` 기본값 `false`, fork 빌드는 `BUILD_HASH` 만 전달. CI 의 `awk` 주입(`FROM … node:` 직후 `NODE_OPTIONS`)을 새 Dockerfile 에 그대로 실행해 1줄 주입 확인.     |
| `requirements-min.txt` 삭제 → `requirements-slim.txt` | fork 참조 없음 (`backend/AGENTS.md` 설명 1줄만 — 갱신 대상)                                                                                                                     |
| **`langchain-community` 제거 (브레이킹)**             | fork 소유 코드(`pipelines/`, `scripts/`)·`backend/` 에 참조 0건. **단, 프로덕션 DB 의 워크스페이스 Tool/Function 이 직접 import 하는지는 저장소로 확인 불가 → §5 게이트 항목.** |
| `FONTS_DIR` 제거, `REDIS_TASK_TTL`(300s) 신설         | fork 배포 설정에 참조 없음, 프로덕션 compose 에 redis 없음 → 무영향                                                                                                             |
| `middleware.py` +568/-235                             | fork 의 필터 파이프라인 경로가 지나는 파일. **§5 게이트에서 pipelines 필터 inlet/outlet 확인 필수** (v0.11.3 게이트가 이 경로를 검증하지 못했던 선례, `docs/jobs/2026-09-04`)   |
| 보안 권고 ("Security Advisory")                       | 릴리스 노트가 "열거되지 않은 수정 포함, 프로덕션 업데이트 권장" 명시                                                                                                            |
| 브랜딩 보호 주석 (`env.py`)                           | v0.11.3 에도 동일하게 존재, 런타임 로직 변경 없음                                                                                                                               |
